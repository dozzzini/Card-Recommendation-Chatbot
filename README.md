# 카드 상품 추천 대화형 AI 구현

## 1. 프로젝트 개요 (Overview)
본 프로젝트는 카드 상품 데이터를 기반으로, 사용자 페르소나에 맞는 카드 상품을 추천하는 **대화형 AI 시스템**을 구현하는 것을 목표로 합니다. 
기본 LLM 응답과 프롬프트 엔지니어링 및 RAG(Retrieval-Augmented Generation)를 적용한 응답을 비교하여, 추천 정확도와 응답 품질의 차이를 평가합니다.

---

## 2. 프로젝트 목표
- 카드 상품 데이터 기반 추천 시스템 구현
- 사용자 페르소나를 고려한 대화형 카드 추천
- 프롬프트 엔지니어링 및 RAG 적용을 통한 모델 고도화
- Human-based Evaluation을 통한 추천 성능 검증

---

## 3. 데이터 수집
### 3.1 데이터 출처
- 카드고릴라 (https://www.card-gorilla.com)
- 신용카드 / 체크카드 상품 정보

### 3.2 수집 방식
- 카드 리스트 페이지에서 카드 상세 페이지 URL 수집
- 카드 상세 페이지 단위 크롤링
- **카드 1개 = JSON 파일 1개** 구조로 저장

### 3.3 데이터 구성 필드
- 카드명
- 카드사
- 카드 유형 (신용/체크)
- 연회비
- 주요 혜택
- 카드 설명
- 원본 URL

---

## 4. 사용자 페르소나 설정
총 3가지 이상의 사용자 페르소나를 정의하여 카드 추천 시나리오를 구성합니다.

예시:
- 20대 취업준비생 (대중교통, 편의점 중심 소비)
- 30대 직장인 (해외여행, 병원, 자차 이용)
- (추가 페르소나 작성)

---

## 5. 시스템 구조
### 5.1 Base 모델
- GPT-3.5-turbo
- 프롬프트 기반 카드 추천 응답 생성

### 5.2 고도화 구조
- 프롬프트 엔지니어링 적용
- 카드 데이터 기반 RAG 구조 구현
- 벡터 검색 결과를 기반으로 한 카드 추천 응답 생성

---

## 6. 모델 평가
### 6.1 비교 평가
- Base GPT 응답 vs 프롬프트 + RAG 응답 비교

### 6.2 Human-based Evaluation
- 페르소나별 최소 10회 이상 카드 추천 수행
- 카드고릴라 홈페이지 직접 확인을 통한 추천 적합성 검증
- 평가 기준: 상 / 중 / 하
- 결과 통계 분석

---

## 7. 협업 방식
- 개인 GitHub 레포지토리 기반 협업
- 브랜치 전략:
  - main: 최종 제출용
  - develop: 통합 브랜치
  - feature/*: 역할별 작업 브랜치
